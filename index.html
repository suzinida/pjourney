도구 개발 절차

  1. 수업 문제

    학년의 도달점에 비추어 학생이 스스로 확인해야 할 것이 무엇인지 정합니다.

    생성형 AI(Claude)로 동작 인식, 시간 기록, 판정 알고리즘을 설계합니다.

  3. 현장 시연과 수정

    실제 수업의 기기·조명·공간에서 시연하며 인식 오류와 조작 단계를 고쳐 나갑니다.

  4. 배포

    GitHub Pages로 배포해 학생이 QR 하나로 설치나 회원가입 없이 접속합니다.
